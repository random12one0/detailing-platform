## R2-04 — A wrong expense can never be fixed or deleted; the only way to add one is permanent.

- **Roadmap:** 101.1
- **Severity:** before
- **Category:** opportunity
- **Area:** Money
- **Found by:** looks auditor (claude-sonnet-5-5)
- **Second check:** confirmed by opus — The expense rows at app/src/screens/Money.jsx:999-1024 are plain divs with no onClick; the only button is the receipt thumbnail, which opens the receipt viewer. The only app write to the expenses table is the insert at app/src/components/ExpenseModal.jsx:124-131 (receipts.js only touches receipt fields), and Money.jsx:1063-1068 itself says the sheet 'is add-only ... there is no way to reopen a saved one'. No open ROADMAP item covers editing or deleting an expense; the closest open items are 97.29 (row cap) and 4.1 (job undo), and neither is about this.
- **Supposed to:** A detailer who typed $1,890 instead of $189 should be able to correct or remove the expense so profit is right.
- **What the code does:** The expense list rows are plain text (no tap action) and the only code that writes to the expenses table is the insert in ExpenseModal. The Money screen's own comment says the sheet is add-only. Receipts can be removed, the expense itself cannot.
- **What happens:** One slip of the thumb on a phone number pad permanently lowers 'Earned less expenses' and the accountant export for that month, and the detailer has no way to correct it short of contacting support.
- **Fix:** Make each expense row open the same sheet with the saved values, with Save changes and a ConfirmTap Delete.
- **Reproduce:** Money > Expenses > Add, save any amount, then try to tap the new row: nothing opens.
- **Impact:** Every detailer who logs expenses; wrong profit and wrong tax export with no fix.
- **Benefit:** Profit figures and the export can be corrected, which is the job this screen exists for.
- **Effort:** medium
- **Risk of fixing:** low
- **Confidence:** high
- **Evidence:**
  - file: `app/src/screens/Money.jsx:997-1028`
  - file: `app/src/components/ExpenseModal.jsx:120-131`
