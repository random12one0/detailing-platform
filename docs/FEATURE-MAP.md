# Detailing Platform feature map

**Baseline:** production frontend `6bc63ce2` (2026-11-27); source checked at the same commit. Live observations below are marked individually. Supabase migrations/functions, provider registrations, account flags, and the independent Studio do not ship with the frontend. Refresh evidence for whichever one your change touches.

## Before assigning or writing code

1. Name the entry point and the actual user: platform operator, shop owner/staff, or booking customer. Reproduce the existing behavior in the correct environment and role. A Netlify fallback response is not evidence that a route works.
2. Trace **UI → saved state → server rules → customer-visible result**. Find existing screen, helper, schema/migration and regression test; search by both the on-screen label and the stored field. Check open issues and worktrees/PRs before assigning another implementation.
3. Record which link is missing and what can be reused. A working form, stored draft, database column, or active phone number is not an end-to-end feature. If an existing feature is disconnected, repair the connection instead of adding a parallel screen or data model. If a second path is necessary, state why and what happens to older data and links.
4. In the handoff, list the starting commit, reuse points, an end-to-end regression check, and what is not verified. Update the relevant row when a feature changes. GitHub Issues track pending work; this file maps the product, not the backlog. Use [BUSINESS-RULES.md](../BUSINESS-RULES.md) and the [DECISIONS.md](../DECISIONS.md) index for intent. Older status and handoff docs are dated evidence, not current authority.

**Status key:** **Live verified** means the actual deployed route or behavior was observed. **Built** means the code exists in the baseline, not that every feature was re-tested live. **Test mode** means no real customer charge/message. **Draft/gated** means not applied or enabled. **Branch only** means not in this baseline. Mark unknowns instead of treating them as bugs or done.
