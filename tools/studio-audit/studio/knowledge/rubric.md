# The must-have rubric (every Studio site, no exceptions)

"If the detailer has it" means the section shows when the dashboard has the data and disappears when it does not.

| # | Must-have | Checked by |
|---|---|---|
| M1 | Booking built into the site, in its own design. A Book button on every page; Book above the phone fold; step one in two taps. It asks, never computes. | G3, connection check |
| M2 | Every active service, in its group, with price, "from" prices, size ladder, duration, inclusions, notes | G0, connection check |
| M3 | Add-ons, if any | G0 |
| M4 | Monthly plans, if any | G0 |
| M5 | The site-wide sale while one runs | G0 |
| M6 | Real photos of their work, before/after where they have pairs. Never AI images of claimed work | G0, critic |
| M7 | Reviews with their source, shown as the form's answer says | G0, critic |
| M8 | FAQ, if any | G0 |
| M9 | How to pay | G0 |
| M10 | Hours and the area served | G0, G3 |
| M11 | Name, phone (call and text), email, socials | G3 |
| M12 | Never contradicts the booking mode (mobile, drop-off or both; request or instant) | G0 |
| M13 | Mobile first: designed at 390 wide, no sideways overflow, 44 px tap targets | G1 |
| M14 | Accessible: WCAG AA contrast, keyboard, one h1, skip link, visible focus | G2 |
| M15 | Fast on a phone | G4 |
| M16 | Calm motion: transform and opacity only, everything visible with reduced motion, no scroll hijack | G5 |
| M17 | Local search basics, all filled from the dashboard | G3 |
| M18 | Honest: says only what the detailer allowed, never what they forbade, no invented claims, no numbers typed into wording | G0, critic |

## Features, switched on per detailer (never added silently; each is proposed as a card)
Before/after slider (needs matched pairs), plans page, owner's face and story, ceramic coating explainer with
"quote after we see it", gift cards, "what to have ready" for mobile work, service-area list or map, Spanish
version, fleet and commercial section, multi-page. Cards cannot switch features on yet: if he asks for one, say
it is a later step and make no card.

For wording, M12 and M18 matter most: the words must match how booking really works and must not promise what
the detailer has not said.
